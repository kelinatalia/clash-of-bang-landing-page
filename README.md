# Clash of BaNG

## Overview
Clash of BaNG is a fantasy strategy game landing page, built as an HCI (Human Computer Interaction) lab project. The site has multiple pages covering the game's home page, troop gallery, about section, and registration page.

## Pages
- Home, hero section, latest news carousel, and elite units showcase
- Gallery, with filtering and pagination for game assets
- Troops, showcasing playable units
- About
- Register

## Features
- Rotating background carousel on the hero section
- Filterable and paginated gallery
- Milestone section with auto centering

## Design
The visual design was first prototyped in Figma (`clashofBang.fig`) before being built into HTML, CSS, and JavaScript.

## Tech Stack
HTML, CSS, JavaScript
